# Read this first
This folder is the **vintage-sketch-studio** skill. Before doing anything in this folder, read `SKILL.md`, then `references/style-spec.md` and `assets/props/PROPS.md`. They define how every video in this style is cut: the look, the host, the props, the pacing, the transitions, the sound and what gets delivered.
- If the user asks to install, follow `SETUP.md`.
- If the user sends a voice-over, follow the Workflow in `SKILL.md`.
